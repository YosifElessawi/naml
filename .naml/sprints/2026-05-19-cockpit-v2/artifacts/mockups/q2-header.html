Question 02 / Header

What gets pinned to the top of every view?

The header is the only persistent action surface. It has to carry identity, sync health, project + sprint context, navigation, and (maybe) the two big buttons. Trade-off: how much do you want to do from anywhere vs. how clean does it stay?
← all questions ← Q1
RECOMMENDATION
Option A — slim single-row header. Identity + sync + project switcher + active-sprint pill (with mini progress bar) + route tabs + notifications + account + gear. Run Sprint / Merge Sprint stay on the Sprint view, not the header — they're context-sensitive, only meaningful when you're already there. A header that's always actionable is also always loud; a header that just navigates stays calm.
